# Instruções do repositório

- Adicione comentários ao código somente quando o usuário pedir.
- A cada alteração entregue no aplicativo, incremente a versão de patch, salvo quando o usuário indicar outra versão. Use o `Cargo.toml` como referência e sincronize o `Cargo.lock`, o `package.json` e as versões dos manifestos de empacotamento. Ao preparar uma release, atualize as notas da versão e o histórico AppStream.
